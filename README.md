# "Framework" multicritério para priorização de melhorias em plataforma digital de processos seletivos

Este repositório contém a base de dados brutos e dados de validação referentes ao Trabalho de Conclusão de Curso (TCC) para obtenção do título de especialista em Data Science e Analytics pela USP/ESALQ .

## 📌 Sobre o Projeto
O estudo desenvolveu e validou um framework multicritério de apoio à decisão para a governança de produtos digitais no terceiro setor. O modelo substitui o planejamento empírico tradicional (heurístico) por uma abordagem orientada a dados na gestão de melhorias de uma plataforma digital de recrutamento e seleção (ATS).

A modelagem matemática utilizou o método **PrOPPAGA** (Prioridade Observada a Partir da Presunção de Atitude Gaussiana das Alternativas) para ordenar de forma consistente um backlog de 64 demandas sob a ótica de 9 critérios operacionais, de negócio, de segurança e de experiência do usuário (UX).

## 📂 Estrutura do Arquivo de Dados
O arquivo principal **`Apêndice - TCC MBA DSA 2026.xlsx`** está organizado nas seguintes abas, correspondentes às tabelas de auditoria citadas no corpo do TCC:

*   **Tabela A1:** Matriz de decisão final dos ítens do “backlog” após validação da coordenação de R&S.
*   **Tabela A2:** Priorização gerada pelo "framework" para priorização de melhorias na plataforma.
*   **Tabela A3:** Grupos de prioridade do modelo de "framework" e de controle, e “ranking” do modelo de controle, cenário de estresse técnico e cenário de estresse de negócio.
*   **Tabela A4:** Consolidação do Índice de Validade de Conteúdo (IVC) dos Peritos e respostas recebidas via formulário eletrônico para a pergunta: “Considerando o "framework" de priorização apresentado e a realidade da governança da nossa plataforma ATS, compartilhe suas principais impressões.
